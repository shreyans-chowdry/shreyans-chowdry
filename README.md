## # Systems

### [RaftKV](https://github.com/shreyans-chowdry/raftkv)
A fault-tolerant, linearizable key-value store on a from-scratch Raft implementation. 500 seeded chaos runs — partitions, crashes, dropped messages — checked with Porcupine, zero failures.

`Go` `Raft` `gRPC` `Distributed systems`

### [ChronoDB](https://github.com/shreyans-chowdry/chronodb)
A Git-inspired relational database engine. Branch, diff and time-travel your data with `AS OF` queries.

`Python` `Databases` `Version control`

### [QueueForge](https://github.com/shreyans-chowdry/queueforge)
Distributed background jobs with priorities, delayed execution, retries and failure recovery. Redis + PostgreSQL, Dockerized workers, live monitoring.

`Python` `Redis` `PostgreSQL` `Docker`

### [pgara](https://github.com/shreyans-chowdry/pgara)
Profile-guided adaptive register allocation that skips graph coloring: stochastic dynamic programming scores each value, and a game-theoretic auction settles who gets the register.

`Compilers` `Dynamic programming` `Game theory`

## # Tools

Useful things, built to be used.

- **[KernelLens](https://github.com/shreyans-chowdry/KernelLens)** — Root-cause analysis for Linux kernel logs: parsing, an ML anomaly filter, event correlation, then an LLM explanation.
- **[CodeAtlas](https://github.com/shreyans-chowdry/codeatlas)** — Ask any GitHub repo questions in plain English and get answers grounded in its code.
- **[ResearchMate](https://github.com/shreyans-chowdry/research_mate)** — A six-agent pipeline that searches papers, reads them, and drafts a review with cited research gaps.
- **[Parchi](https://github.com/shreyans-chowdry/parchi)** — Turns orders sent by chat, voice note or photo into invoices, in seven languages. [Live demo →](https://parchi-two.vercel.app)
- **[TravelCraft](https://github.com/shreyans-chowdry/travelcraft)** — A trip planner that optimizes which places to see, which day, and in what order around opening hours. [Live →](https://travelcraft-liard.vercel.app)
